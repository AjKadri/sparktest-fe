## What this changes for the library

1. **Wasm in the browser is viable, so make it the demo.** The exported surface must be scalar-only: each property gets a thin `#[unsafe(export)]` wrapper such as `run_below(seed: u64, cases: u32, limit: u64) -> u32`, and results come back through `extern` callbacks (here `qc_fail`). This works because callbacks are plain JS imports. Generic runners stay internal.
2. **Ship three ingots:** `qc` (pure core), plus per-target reporters. Shared code can't live in a standalone file, and one file can't mix `Evm` and `Stdout` tests. Use `target = "native"` in the native test ingot's `fe.toml`, and `fe test --ingot` from a workspace.
3. **The runner must be declared `uses P::E`.** There is no way (found) to demand a pure property, so effectful properties are allowed by default, which is fine, but the docs should say the test supplies the effects.
4. **Shrinking works as designed** with the `shrink_step(self, i)` protocol; tuple, array and struct shrinkers compose. Cost is O(n²) in the candidate count (`count_candidates` re-counts per call); acceptable at these sizes, but cache it or switch to an iterator-style protocol later.
5. **Use `<T as Arbitrary>::arbitrary(..)` or generics in all library code**, never `Type::arbitrary(..)`, to avoid E7a on std types (Address, Option).
6. **Failure reporting:** on sonatina use `revert_error(PropertyFailed{…})`; test `#[test(should_revert, selector = 0x30fd945a)]` only checks the selector. On native/wasm print. In the browser use the `qc_fail` callback.
7. **Don't trust unknown `#[test(...)]` keys**: they are silently ignored.
