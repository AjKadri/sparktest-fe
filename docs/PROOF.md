# Sparktest proof

Generated by `scripts/proof.py` (run `./scripts/proof.sh`); do not edit by hand. Expected minimums were written down before the suites
were run, in [EXPECTATIONS.md](EXPECTATIONS.md). Case numbers are 1-based. "found" is the shrunk (minimal) counterexample.
Sparktest shrinks greedily, so it finds a local minimum, not always the global one.
