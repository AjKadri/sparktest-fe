## Things that change the library design

1. **Report failures via revert data, not logs (sonatina).** Define one `#[error] struct PropertyFailed { input, case, seed }` and revert with it. Logs work only on passing tests (e.g. to emit stats such as case count and gas used).
2. **Two targets, two effect sets.** To run on both backends, keep the core effect-free (pure `Arbitrary` + `Rng` + `Fn` generics) and put reporting in thin target-specific shims: `Evm` revert on sonatina, `Stdout` on native. One test file can't mix both effects.
3. **Gas ceiling of 1e9 per test on sonatina.** Default case count should be small (100–1000), configurable, with the gas cost per case documented. Native can run millions of cases.
4. **Constant folding.** A deterministic pure property with a fixed seed can be folded at compile time, which is fine for correctness but makes any gas/timing claim meaningless. Seed from the environment (`evm.prevrandao()` / `evm.gas()`) when a runtime-dependent run is wanted; for reproducibility, take the seed as a parameter and print it on failure.
5. **Prior art in std:** `std::evm::random` already has `trait Rng { fn next(mut self) -> u256 }` (`KeccakRng`, `ReplayRng`) used as an effect (`uses (rng: mut Rng)`), plus `uniform`, `shuffle`, `choose`. Build `Arbitrary` on top of `Rng` instead of a bare seed to avoid reinventing it, and to be idiomatic. KeccakRng is slower than xorshift per word, so keep a cheap xorshift `Rng` impl as the default.
6. **Shrinking** was not tested. Closures can't mutate captures, so shrinkers should be pure `fn shrink(x) -> candidate` steps driven by a loop in the runner.
7. **Calling static trait methods** needs `<T as Trait>::f(..)` or generics; `Type::f(..)` didn't resolve for a trait-provided associated function.
8. Not tested: the wasm backend, `#[test(should_revert)]` for the "property must fail" tests, and generic `Arbitrary` for tuples/structs/arrays.

I killed the slow feup run, so `~/.fe/env` and the `feup` command were not installed. The binary is not checksum-verified.
